Turn your coding assistant into a full video studio: hands-on with OpenMontage

Describing a video in plain language and getting a finished cut back used to be a demo-day fantasy. OpenMontage (calesthio/OpenMontage) makes it a repo you clone: the self-described first open-source, agentic video production system — past 67,000 GitHub stars, AGPL-3.0 — that turns Claude Code, Cursor, Copilot, Windsurf, or Codex into a full studio. It researches your topic, writes and narrates the script, sources footage or generates it, scores a soundtrack, burns in word-level captions, and renders — with a multi-point self-review before you ever see the cut. This tutorial installs it, renders the zero-key demo, and directs your first video.

MDMarcus DoyleSenior Technology Writer · October 12, 2026 · 6 min read

What you’ll need

  • Python 3.10+, Node.js 18+, and FFmpeg — the three hard prerequisites. On macOS: brew install ffmpeg; on Debian/Ubuntu: sudo apt install ffmpeg.
  • An AI coding assistant — Claude Code, Cursor, Copilot, Windsurf, or Codex. This is not a point-and-click app: the assistant is the director, the editor, and the sound designer. The quality of your video scales with the quality of your agent.
  • Zero API keys to start. The free path uses Piper TTS for narration, Archive.org + NASA + Wikimedia Commons for real footage, and Remotion/HyperFrames + FFmpeg for rendering — all local, all free. Paid providers (Veo, Kling, ElevenLabs, Suno) are optional upgrades, each a line in .env.
  • Disk space and patience. make setup installs a Python venv, npm packages for the Remotion composer, and the Piper TTS model. The first video takes a while; that is the agent doing research, scriptwriting, asset generation, and editing.

1. Install it

Three commands:

git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup

If you don’t have make, the README gives the manual equivalent (venv + pip install -r requirements.txt + npm install in remotion-composer + pip install piper-tts + copy .env.example to .env). Open the project folder in your coding assistant and you are on the set.

Sanity-check the install with the zero-key demo, which renders sample videos instantly without touching any provider:

make demo

What comes out is a fully rendered video — narrated, captioned, scored — built with nothing but free local tools. If the demo renders, your pipeline is healthy.

2. Direct your first video

With the project open in your assistant, type a plain-language brief. This one is straight from the project’s own quick start:

"Make a 60-second animated explainer about how neural networks learn"

Here is what the agent actually does behind that one sentence: it researches the topic with live web search, writes a script with voice direction, generates images, narrates them with Piper TTS, finds royalty-free background music automatically, burns in word-level subtitles, and renders the final cut. Before you see anything, the system runs a multi-point self-review — ffprobe validation, frame sampling, audio level analysis, and subtitle checks.

When it finishes, every creative decision comes with your approval gate, and every provider selection is scored across 7 dimensions with an auditable decision log. You are the producer; the agent is the crew.

3. Try the real-footage documentary path

OpenMontage’s most interesting trick is that it is not limited to animating stills. Ask for the documentary montage pipeline and it builds a CLIP-searchable corpus from Archive.org, NASA, and Wikimedia Commons, retrieves actual motion footage, and cuts it into a timeline:

"Make a 75-second documentary montage about city life in the rain. Use real footage only, no narration, elegiac tone, with music."

That prompt is also from the README, and it exercises a genuinely different pipeline: no narration track, footage retrieved by semantic search rather than generated, music laid under a real edit. If you want this path reliably, prompt for a documentary montage, tone poem, or stock-footage collage and say use real footage only explicitly — the project is clear that otherwise the agent may default to the image-based route.

4. Add keys when free stops being enough

Copy .env.example to .env if make setup didn’t already, and add only what you need. Every key is optional; more keys mean more tools, not a different product:

# Free stock media (developer keys are free to get)
PEXELS_API_KEY=your-key        # free stock footage and images
PIXABAY_API_KEY=your-key       # free stock footage and images

# Image + video gateway (paid, per-use)
FAL_KEY=your-key               # FLUX images + Veo, Kling, MiniMax video

# Voice & music (paid, per-use)
ELEVENLABS_API_KEY=your-key    # premium TTS, AI music, sound effects
SUNO_API_KEY=your-key          # full songs, instrumentals, any genre

Have a GPU? make install-gpu unlocks free local video generation (Wan 2.2, Hunyuan, LTX, CogVideo models), enabled with VIDEO_GEN_LOCAL_ENABLED=true in .env. To calibrate your expectations on cost, the project’s own showcase — a 60-second animated short, six generated motion clips, AI narration, royalty-free music, TikTok-style captions — cost $1.33 end to end.

What you built

A working agentic video studio: 12 production pipelines, 100+ tools, and 700+ agent skill files wired into whatever coding assistant you already use. You can now go from a sentence to a rendered, narrated, captioned video — or from a reference clip you paste in to 2–3 differentiated concepts with cost estimates before production starts. The reference-video path is the sleeper feature: paste a YouTube Short you like, and the agent analyzes its transcript, pacing, scenes, and style, then proposes what it keeps, what it changes, and what it will cost at your target duration.

Honest limitations

  • Your agent is the bottleneck. OpenMontage is a skill-and-pipeline layer; the actual directing, taste, and error recovery come from the coding assistant you plug in. A weak agent produces a weak video with extra steps.
  • The showcase runs on paid providers. The cinematic trailers in the README lean on Veo, Kling via fal.ai, and Google Chirp narration. The zero-key path is genuinely functional, but Piper narration and archival footage will not look like a $4 Kling render — budget accordingly.
  • It is young and moving fast. The project was created in March 2026 and sits at 67K+ stars on momentum; pipelines, prompts, and provider menus are still evolving. Pin a commit if you build on it.
  • AGPL-3.0. Free to use and modify, but if you fold it into a commercial product or hosted service, read the license first — the copyleft obligations are real.
  • Local video generation is heavy. The GPU path wants a serious card and serious disk. On a laptop, stay on the API or stock-footage paths.
