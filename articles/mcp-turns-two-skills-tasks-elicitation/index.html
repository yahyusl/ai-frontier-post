MCP turns two: servers can now ship skills to Claude and hand off long jobs as Tasks

Two years after launching MCP, Anthropic is giving the protocol its biggest upgrade yet: servers can now ship skills alongside their tools, run long jobs in the background, and pause to ask users a question — with file uploads coming next.

Two years after Anthropic launched the Model Context Protocol, the standard that lets AI agents reach into outside software is getting its biggest upgrade yet. Servers can now ship skills alongside their tools, run long jobs in the background, and pause mid-task to ask the user a question. File uploads are coming next.

Anthropic announced the updates on Tuesday, marking the second anniversary of MCP, which it introduced in November 2024 as an open standard for connecting agents to the systems where data lives. The protocol has since become the default plumbing for agentic software: Anthropic says its developer tools now see more than 700 million downloads a month, and there are more than 10,000 MCP connectors for Claude.

Skills over MCP: the playbook travels with the tool#

Until now, a server could tell Claude what it could do — its tool names and descriptions — but not how to do it well. Skills over MCP closes that gap: servers can publish skills next to their tools, covering best practices, step-by-step workflows, or playbooks tailored to a user’s account or organization. Claude loads a skill only when it is needed, keeping context use low, and the skill updates with the server, so users have nothing extra to install.

Anthropic’s launch examples show the range. Shopify’s skill helps Claude design and update a merchant’s online store end to end; HubSpot’s onboards customers and gets them set up in Claude; Atlassian’s draws on deep organizational context for insights and work analysis; Carta’s, coming soon, will help Claude draft and issue equity from an uploaded document.

The feature is in public beta in Claude and Claude Code, on by default for Pro, Max, and Ultra plans, available to Team plans once an admin enables it, and coming soon to Enterprise.

Tasks and Elicitation: long jobs, and a pause button#

The second half of the update is about time. Tool calls used to have to finish before Claude could move on. With Tasks, a server can run operations that take a while — or even full agent loops — in the background while Claude keeps working and picks up the result when it is ready. ZoomInfo is using it for deeper account and contact research that previously took several prompts.

Elicitation handles the opposite problem: the moment a job needs a human decision. A server can pause to ask the user for input through a form or link, then continue where it left off. The examples Anthropic gives are all about consequential actions: Supabase confirms costs before creating a paid project and before running destructive SQL; Railway asks before potentially destructive changes like removing a service; GitHub has users enter a repository’s name before an agent deletes it.

Both are now generally available in Claude and Claude Code for Pro, Max, and Ultra plans, and rolling out to Team and Enterprise organizations. Anthropic notes the two features went through a public test in October before reaching general availability.

File Uploads is next, and the numbers behind the anniversary#

The third piece, File Uploads, is rolling out soon. It lets Claude pass files to MCP servers, not just text — PDFs, spreadsheets, and images sent directly to a server without passing through the context window. It will reach Pro, Max, Ultra, and eligible Team and Enterprise plans.

Underneath the new features, Anthropic points to a year of quieter work on the foundations. Tool search now loads tool definitions only when needed, which the company says can cut the context they use by more than 85 percent in multi-server setups. The latest MCP spec is stateless and supported across Claude products; Enterprise Managed Auth lets admins authorize supported servers once so employees connect automatically; and MCP Apps brings full interfaces into Claude, beside the conversation or in full screen.

Why it matters#

The through-line is a shift in what an MCP server is. At launch it was a way to plug data and tools into a model. With skills, background tasks, mid-call questions, and file exchange, Anthropic describes Claude working with a server more like it works with another agent: learning from it, delegating to it, and exchanging input and files along the way.

That framing matters for trust as much as for capability. Elicitation is the safety valve: the more authority servers get over long-running, consequential work, the more the pauses matter — a cost confirmation before a paid project, a name check before a deletion. Anthropic is shipping the autonomy and the checkpoint in the same release.

It also matters that none of this is Claude-only. The features are part of the open MCP spec and its extensions, so a server that supports them works in any compatible client. The protocol is hosted by the Agentic AI Foundation and shaped by the community that builds on it, and the anniversary numbers — 700 million monthly SDK downloads, 10,000-plus connectors — suggest the standard has outgrown any single vendor’s product.

What to watch#

Three things to track from here. First, the Enterprise rollout: Skills over MCP is still coming to Enterprise, and Tasks and Elicitation are still rolling out to Team and Enterprise organizations — the features land in production unevenly. Second, File Uploads: the timing and limits of the rollout will show how much of the context-window bottleneck Anthropic is willing to move off-model. And third, adoption beyond Claude: the extensions only reshape the ecosystem if other clients pick them up, so watch whether the wider MCP community ships skills, tasks, and elicitation as fast as Anthropic did.

Frequently asked questions

What is MCP?

The Model Context Protocol, an open standard Anthropic launched in November 2024 for connecting AI agents to the systems where data lives. It is now hosted by the Agentic AI Foundation, and Anthropic says its developer tools see more than 700 million downloads a month.

What is the difference between a skill and a tool?

A tool description tells Claude what a server can do; a skill tells it how — best practices, step-by-step workflows, or playbooks tailored to an account or organization. Claude loads a skill only when it is needed, and the skill updates with the server, so there is nothing extra to install.

When do I get these features?

Skills over MCP is in public beta now in Claude and Claude Code, on by default for Pro, Max, and Ultra plans, available to Team plans once an admin enables it, and coming soon to Enterprise. Tasks and Elicitation are generally available for Pro, Max, and Ultra, and rolling out to Team and Enterprise. File Uploads is rolling out soon.
