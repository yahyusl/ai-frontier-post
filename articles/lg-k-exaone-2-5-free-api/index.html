K-EXAONE 2.5 free API: LG's 750B model rivals DeepSeek and GLM on agentic benchmarks

LG AI Research has opened free API access to K-EXAONE 2.5, the lab's 750-billion-parameter model, starting November 9. Anyone can get an API key and use it for service development and research at no cost — and LG says the model now trades blows with DeepSeek-V4.1-Flash and GLM-5.3 on agentic benchmarks.

MDMarcus DoyleSenior Technology Writer · November 9, 2026 · 7 min read
TL;DR: LG AI Research opened free API access to K-EXAONE 2.5 on November 9, 2026: a 750-billion-parameter mixture-of-experts model (31 billion active per token) that developers can now call for free with just an API key. LG reports the model improved more than 70% over its August predecessor across 24 evaluation metrics, and says it now sits level with DeepSeek-V4.1-Flash and GLM-5.3 on agentic coding and tool-use benchmarks. Every benchmark is LG's own measurement — no independent evaluation exists yet — and the release is API access only, with no open weights announced for version 2.5.
  • Announced: November 9, 2026, by LG AI Research at NVIDIA AI Day Seoul 2026, held at COEX in Seoul — free API access to K-EXAONE 2.5 through the EXAONE API Platform.
  • What it is: a 750-billion-parameter mixture-of-experts model with 31 billion active parameters per token — text-only, in Korean and English, with a 512K-token context window and a January 2026 knowledge cutoff.
  • Cost: free. Developers, startups, companies, and research institutions need only an API key; LG has not said how long free access will last.
  • Benchmarks (LG's own, on open datasets): AutomationBench 74.6, SWE-Bench Pro 59.2, BrowseComp 78.0, and Claw-Eval 77.3 — more than 70% better than the August model across 24 evaluation metrics.
  • Access: an OpenAI-compatible POST /v1/chat/completions endpoint with model ID k-exaone_v2.5, supporting chat, tool calling, structured outputs, code generation, and streaming.
  • Next: LG aims to complete a frontier-class third-phase EXAONE model by January 2027, and is reviewing NVIDIA's Dynamo inference technology to speed the model up.

LG AI Research has put its biggest model in developers' hands — for free. Announced November 9 at NVIDIA AI Day Seoul 2026, the K-EXAONE 2.5 API is now open to anyone who signs up for an API key on the EXAONE API Platform. No pricing tier, no waitlist: developers, startups, companies, and research institutions can use the 750-billion-parameter model for service development and research at no cost, starting today.

That is a notable shift for a lab that, until now, reached outside developers mainly through open weights. K-EXAONE 2.0, released in August 2026, shipped as a 750B-parameter model under Apache 2.0 — but version 2.5 is a hosted API, not a weights release. LG has not announced open weights for 2.5, and has not said how long the free access will last. What it has said is that the free period is a deliberate test: the lab wants to see how the model performs in real service environments before the third-generation model arrives.

A technology-validation model#

K-EXAONE 2.5 is what LG calls a technology-validation model: the August model with additional post-training applied, built to prove out the training techniques that will go into the third-phase EXAONE. The architecture is a sparse mixture-of-experts — 750 billion total parameters, with 31 billion active on any given token — which is why it can be served at a cost LG is willing to eat for now. It handles text only, in Korean and English, with a 512K-token context window and a January 2026 knowledge cutoff.

Using it should feel familiar. The endpoint is OpenAI-compatible — POST /v1/chat/completions with model ID k-exaone_v2.5 — with chat, tool calling, structured outputs, code generation, and streaming. The docs include agent guides for the Hermes general agent and the OpenCode coding agent, and expose reasoning controls directly: reasoning_effort defaults to max, and preserve_thinking can carry earlier reasoning into multi-turn requests. The main constraint is the context budget: input tokens plus the generation allowance cannot exceed 524,288 tokens per request.

The numbers — and the caveats#

LG's pitch is agentic performance. On its own measurements, run on open datasets, K-EXAONE 2.5 scores 74.6 on AutomationBench (SaaS tool-use automation), 59.2 on SWE-Bench Pro (agentic coding), 78.0 on BrowseComp (agentic web search), and 77.3 on Claw-Eval (agent problem-solving in work environments). Against the two Chinese frontier open-weight models LG chose as its comparison set, that is a near-dead heat: DeepSeek-V4.1-Flash scores 74.9, 58.4, 75.8, and 75.8 on the same four, while GLM-5.3 scores 71.6, 64.0, 79.0, and 77.6. LG also says the model improved more than 70% over the August version across a combined assessment of 24 evaluation metrics.

Every one of those numbers is LG's own. There is no independent evaluation yet, and the comparison set is LG's choice — two rivals, on four benchmarks the lab picked. The honest reading: this is a 750B model that, on LG's scoreboard, now belongs in the same conversation as DeepSeek and GLM for agent work, and the free API means anyone can test that claim without paying for the privilege. What to watch#

Three things to watch. First, whether independent evaluations confirm the numbers — a 70% jump over the August model is the claim that will draw the most scrutiny, and the free API makes it checkable. Second, what the free period turns into: LG has not named a price, a rate limit, or an end date, and the platform also lists a smaller EXAONE Tabular model, suggesting a broader hosted lineup is coming. Third, the road to the third-phase model — LG says it is reviewing NVIDIA's open-source Dynamo inference technology to speed the model up, and aims to complete a frontier-class EXAONE by January 2027.

For now, the practical upshot is simple: a 750B-parameter model from a major Korean lab is one API key away, free, through an endpoint your existing OpenAI-compatible code already speaks. The weights are not open this time — but the trial is. And with open-weight giants like Kimi K3.1 Pro and DeepSeek's 284B model running on 64GB of RAM already competing for the same developers, LG's free API is less a giveaway than a bid to be tested.

Frequently asked questions

What is K-EXAONE 2.5?

LG AI Research's 750-billion-parameter mixture-of-experts model, with 31 billion parameters active per token. It handles text only, in Korean and English, with a 512K-token context window and a January 2026 knowledge cutoff. LG opened free API access to it on November 9, 2026.

How do I use the free API?

Get an API key from the EXAONE API Platform at docs.exaone.ai, then call the OpenAI-compatible POST /v1/chat/completions endpoint with model ID k-exaone_v2.5. The API supports chat, tool calling, structured outputs, code generation, and streaming. LG has not said how long free access will last.

How good is it — and can I trust the benchmarks?

LG reports 74.6 on AutomationBench, 59.2 on SWE-Bench Pro, 78.0 on BrowseComp, and 77.3 on Claw-Eval, roughly level with DeepSeek-V4.1-Flash and GLM-5.3. All of those numbers are LG's own measurements on open datasets, with no independent evaluation yet, so treat them as the lab's scoreboard until someone else reproduces them. This release is API access only — LG has not announced open weights for version 2.5.
