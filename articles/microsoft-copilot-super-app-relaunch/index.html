Microsoft turns Copilot into a super-app: one home for chat, code, and always-on agents

Satya Nadella's Friday relaunch folds chat, coding, and persistent agents into a single Copilot app — a 'new OS for work'. The bigger story is underneath: enterprise context, a governed runtime for AI-built apps, and usage-based billing for the agent work that actually costs money.

MDMarcus DoyleSenior Technology Writer · September 27, 2026 · 7 min read

Microsoft just made its biggest bet yet on the future of workplace AI — and it is not a better chatbot. On Friday, CEO Satya Nadella unveiled a rebuilt Copilot that folds chat, coding, and autonomous agents into a single app, which he described as a "new OS for work" spanning models, form factors, and tasks.

The relaunch repositions Copilot from an assistant living inside Microsoft 365 to what the company now calls an orchestration layer for enterprise work. Chat, agents, code, and Office documents all live in one experience — and, significantly, Microsoft says the orchestration, context, and memory are being separated from any single AI model.

One app, four ways to work#

Copilot's new shape is deliberately simple. Three entry points — Home, Code, and Autopilot — sit alongside Office tools running inside the same window, and Microsoft's stated end goal is that users simply describe what they want done while Copilot routes the work to Chat, Cowork, Code, or another capability.

Home is the new front door: it pairs Chat, built for quick questions, with Cowork, the autonomous agent for delegated multistep work that returns a finished result, such as an RFP response or a financial close package. Code is the redesigned coding environment — it turns natural-language instructions into working apps, dashboards, trackers, and workflows, runs in a sandbox that can be hosted inside an organization's own tenant, and shares its underlying technology with GitHub Copilot. Autopilot, the persistent agent formerly known as Scout, takes a name, a role, and a goal from its owner, then watches channels, chases threads, and resumes projects days later on its own — living in the tenant with its own identity, memory, computer, and workspace, and colleagues can @mention it in Teams or Outlook.

Office in Copilot brings Word, Excel, and PowerPoint directly into the app, so a request produces a real editable file that stays synchronized with the Office applications. Home and Code will roll out through Microsoft's Frontier early-access program in the coming weeks, Autopilot expands to private preview at the end of September, and a proactive "Today" command center across email, calendars, Teams threads, meetings, and tasks is expected to enter private preview in October.

Context is the real upgrade#

The more consequential changes sit under the hood. Fabric IQ is now generally available inside Chat and Cowork, grounding Copilot in enterprise data — including, Microsoft says, more than 20 million semantic models in Power BI — with integration into Code coming through the Frontier program. Work IQ, which reaches into data and workflows in Dynamics 365 and Power Platform, enters public preview over the next month.

That plumbing is what lets Copilot reason across a company's actual systems rather than chatting about them. As Avasant principal analyst Abhishek Satapathy put it, the practical shift is "from AI that knows information to AI that can connect what happened, why it happened and what needs to happen next" — a business insight becomes the starting point for analysis and follow-up action, rather than requiring the user to manually move context between reports, documents, conversations, and business systems.

Code for everyone, a runtime for IT#

Code is the bigger philosophical bet. Microsoft calls small, purpose-built apps a fourth unit of knowledge work, next to the document, the spreadsheet, and the deck — and argues that learning to build them is becoming as basic a skill as writing a memo or modeling a budget. The environment aims at the middle ground between traditional development and simple automation: business users can build the internal tools too narrow for a formal development project but too complex for basic automation, while developers use the same environment to accelerate and focus on harder engineering.

For IT, the answer is the Copilot Managed Runtime: a governed hosting environment for applications built with Code, Cowork, and Copilot Studio, running inside an organization's Microsoft 365 environment with IT control over security, governance, and access to live data. The runtime is in public preview and will sit inside the redesigned Code experience. Manoj Chandra Jha, principal analyst at Nord-IQ Research, argues it could give enterprises a common production layer that moves AI-created applications from experimentation to production without a separate operating model for each one — and help IT curb the shadow IT and application sprawl that employee-built apps and agents create, by managing them consistently for security, identity, policies, lifecycle, observability, and deployment.

The meter is running#

The economics of Copilot are changing alongside the product. Usage-based billing now extends to Cowork, Code, Autopilot, long-running agentic capabilities, and frontier models, while Chat and Copilot across Microsoft 365 remain covered by the user subscription license. Metering is not new to the platform — Cowork has billed by usage since its general availability in June — but extending it across the agent stack makes the cost of delegated work explicit.

Microsoft is also expanding its FinOps capabilities in Agent 365 to cover Code and the Copilot Managed Runtime, letting administrators manage AI spending policies at scale, control access to model families, route credit requests through existing approval workflows, and see the outcomes agentic workloads actually produce — sustaining, expanding, or optimizing usage accordingly. End users will be able to view their credit usage, remaining balances, and history directly in Copilot.

That visibility matters because agent bills behave nothing like software licenses. Two employees on the same Copilot license can generate wildly different AI costs depending on whether one asks for assistance and the other delegates long-running work to agents. Bhupendra Chopra, chief revenue officer at IT consultancy Kanerika, argues these tools will be critical for CIOs judging whether automation delivers real business value: correction rates can expose stale context, poor business rules, or an unreliable data foundation before they become larger problems — and, he notes, an enterprise can automate 20 minutes of work only to spend that time elsewhere, meaning the productivity gain counts only when it produces a measurable result.

What to watch#

  • Autopilot's private preview. Does a persistent agent with its own identity, memory, and @mention earn trust inside real tenants — or trigger governance lockdowns?
  • Bill shock. Usage-based pricing makes agent economics legible; watch for the first enterprise stories of runaway agent spend and how quickly FinOps controls tighten.
  • Code's Frontier rollout. Can non-developers actually ship working apps — and does the Managed Runtime keep IT in control when they do?
  • The model question. Nadella's framing separates orchestration from any single model. Watch whether Copilot becomes genuinely model-flexible or stays Microsoft-first.
  • The competitive response. OpenAI is pushing its own enterprise agent platform while Anthropic keeps landing enterprise wins. Copilot's home-field advantage is distribution; the fight is moving to the agent runtime.
