Anthropic launches Claude Ship: AI agents that review, fix, and approve your pull requests

Anthropic’s Claude Ship hands the whole pull-request pipeline — review, fixes, and approval — to three AI agents, with teams writing the policy that decides what can merge without a human. It’s in beta today for Team and Enterprise plans on GitHub.

PNPriya NairResearch Editor · November 23, 2026 · 6 min read
TL;DR: Anthropic launched Claude Ship in beta on Monday, November 23. Three agents — Code Review, already generally available, plus the new PR Steward and Claude Approvals — carry a pull request from review through fixes to an approval decision, governed by a policy file each team writes. It rolls out to Claude Team and Enterprise plans for GitHub repositories, usage is billed on tokens, and Anthropic recommends starting approvals in observe-only mode.
  • The three agents: Code Review (generally available) reviews pull requests against the codebase at Quick, Standard, or Deep depth; PR Steward (beta) fixes failing CI checks, merge conflicts, and review feedback, and never approves or merges; Claude Approvals (beta) applies the team’s written policy and can approve routine changes.
  • The internal evidence: on Anthropic’s own Claude Code team, merged pull requests more than doubled from June to September while the share that had to be reverted fell by more than 40% — Anthropic’s figures, self-reported.
  • How to start: developers run the new /ship command in Claude Code; admins can switch it on per repository, with spend limits and a choice of review level.
  • The price: token-based billing; eligible Enterprise organizations can claim at least $10,000 in Claude Ship credits by January 15, 2027.
  • The limits: not available to organizations with Zero Data Retention, the HIPAA configuration, or customer-managed encryption keys.

Anthropic moved the AI coding race past writing code on Monday, launching Claude Ship, a beta system that lets AI agents take over everything that happens after a pull request opens: the review, the fixes, and — the part that will get the most argument — the approval.

The logic is hard to dispute. On Anthropic’s own Claude Code team, the company says, Claude already writes most of the code. The bottleneck moved downstream: somebody still has to read every change, chase failing checks, and find a human to approve it. Claude Ship is Anthropic’s answer — automate the queue, not just the typing.

Three agents, one pipeline#

Claude Ship is not one agent but three, handing a pull request from one stage to the next. Code Review, already generally available, reads the change against the wider codebase through several lenses, checks its own findings against each other, and posts them to the PR — at Quick, Standard, or Deep depth, per repository.

PR Steward, new in beta, does the chasing: failing CI checks, merge conflicts, and review feedback from Code Review, other tools, or teammates. After every push it comments on what it changed and how to undo it, and developers can steer it with an @claude comment or stop it with @claude stop. It is deliberately barred from approving or merging anything.

Then Claude Approvals, also new in beta, applies an approval policy the team writes as a file in the repository — Anthropic describes it as a smarter CODEOWNERS file. If the policy allows it, Claude can approve routine changes itself; anything else goes to a human. The policy can weigh Code Review’s findings or the team’s own classifiers, written in plain language.

Code ReviewGenerally availableReviews PRs against the codebase, verifies its own findings, posts them to the PRNo
PR StewardBetaFixes failing checks, merge conflicts, and review feedback; reports what it changedNo — it never merges
Claude ApprovalsBetaApplies the team’s written approval policy to decide what can mergeYes, where the policy allows it

The approval agent is the real story#

Review bots are old news. An agent that can sign off on a merge is a delegation of authority, and Anthropic knows it: the company recommends switching approvals on in observe-only mode first, building confidence before branch protection ever depends on Claude’s green light. Teams also keep control of where the system runs, which review level each repo gets, and which changes get escalated to a person.

Anthropic offers its own team as the worked example. A product manager spotted a confusing line in the Analytics API documentation, asked Claude Tag whether a fix was in flight, and Claude Tag opened one. Code Review found nothing blocking, a docs reviewer signed off, Claude Approvals passed, and the fix merged the same evening — with a human still in the loop at the review step. The internal numbers Anthropic cites for the same period are striking, and self-reported: on the Claude Code team, merged pull requests more than doubled from June to September while the share that had to be reverted fell by more than 40%.

What it costs, and who can’t use it#

Claude Ship is billed on tokens, so switching it on can add to an organization’s costs — the amount depends on how many pull requests it covers, how big they are, the review level, and how much fixing PR Steward does. Admins can set spend limits for Code Review and PR Steward. Claude Approvals itself has no base charge, but classifiers in a policy are billed on the tokens they use, and a policy that uses Claude’s review triggers a billed Code Review even in observe mode. Running /ship counts as regular Claude Code usage.

Eligible Enterprise organizations can claim at least $10,000 in Claude Ship credits, to use within 30 days of claiming, by January 15, 2027. And there is a hard exclusion worth noting: Claude Ship is not available to organizations with Zero Data Retention, the HIPAA configuration, or customer-managed encryption keys — the same day Anthropic also put zero-data-retention into public beta for other customers, the new approval tool is closed to exactly those organizations.

Why now — and what to watch#

Anthropic’s announcement post drew about 450,000 views within hours, according to the X trending roundup NoFOMO — a sign of how closely developers are watching the review bottleneck. The timing is no accident: agents now generate code faster than humans can review it, and every vendor in the space is racing to own what happens next.

What to watch: whether teams actually graduate from observe-only mode to letting Claude approve merges, and what happens the first time an approved change ships a bug. Anthropic’s own guardrails — policy files, spend limits, escalation rules — are the product here as much as the agents. If the industry follows, the pull request stops being a human checkpoint and becomes a policy checkpoint, with the human writing the policy instead of reading the diff. That is a bigger shift than another review bot, and it is why this launch matters more than its modest beta label suggests.

Frequently asked questions

What is Claude Ship?

A beta system from Anthropic that automates the pull-request pipeline with three agents: Code Review, which reviews changes against the codebase; PR Steward, which fixes failing checks, merge conflicts, and review feedback; and Claude Approvals, which approves routine changes under a policy the team writes. It launched November 23, 2026, for Claude Team and Enterprise plans on GitHub.

Can Claude Ship merge code by itself?

No. PR Steward is designed never to approve or merge, and Claude Approvals only approves changes a team's written policy allows — anything else goes to a human. Existing branch protection and required checks still apply, and Anthropic recommends starting approvals in observe-only mode.

How much does Claude Ship cost, and who can use it?

Usage is billed on tokens, based on the number and size of pull requests, the review level, and how much fixing PR Steward does. Admins can set spend limits. Eligible Enterprise organizations can claim at least $10,000 in credits by January 15, 2027. It is not available to organizations with Zero Data Retention, the HIPAA configuration, or customer-managed encryption keys.
