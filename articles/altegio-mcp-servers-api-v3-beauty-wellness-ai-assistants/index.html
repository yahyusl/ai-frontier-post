Altegio opens salons to AI assistants: MCP servers and API v3 put bookings, clients, and revenue inside ChatGPT

Altegio announced this morning at Web Summit 2026 in Lisbon an open platform that plugs its booking software into AI assistants: six MCP servers and a new Business Management API v3 let salon and spa owners ask ChatGPT or Claude about their bookings, clients, and revenue — and let developers build agents on top of the same data. The platform serves more than 14,000 appointment-based businesses across 90-plus countries.

The verdict: This is the most practical MCP launch of the year for a non-tech industry — it puts a real business database behind plain-language questions a salon owner actually asks. The catch is scope: API v3 is still in early access, and how much each assistant can do depends on the plan and the assistant.

What we checked: Altegio’s FinanceWire press release “Altegio Announces Open Platform Connecting Beauty and Wellness Businesses With AI Agents at Web Summit 2026” (November 9, 2026, 10:00 a.m. UTC), cross-checked against Kalkine the same day.

Picture a salon owner at 8 a.m., coffee in hand, opening her laptop to a wall of dashboards: bookings, no-shows, revenue by service, staff schedules. Now picture her asking a question instead — out loud, to ChatGPT — and getting the answer. That is the scene Altegio staged in Lisbon this morning, and it is the whole pitch: the dashboard is optional now; the data answers back.

The launch matters because of who it is for. MCP servers have mostly served developers and enterprises so far. Altegio is pointing the same protocol at hair salons, spas, and nail studios — businesses where the owner is also the receptionist, the marketer, and the accountant.

What Altegio actually launched

The platform has two halves. The first is six MCP servers built on the Model Context Protocol, the open standard that lets AI assistants connect to outside services. The second is Business Management API v3, now in early access, built for developers and AI agents.

Altegio Pro MCPManage bookings, staff, services, work schedules, clients, and location settingsOwners and managers

The release gives three example questions an owner can now ask: “Which clients haven’t visited in over 90 days?” — the assistant builds the list from visit history for the next marketing message. “Move Anna’s appointment to 3 p.m. with Maria.” — it checks the calendar and suggests the change. “How did revenue change this month, and which services grew?” — it compares the periods and breaks revenue down by service and employee. Setup takes three steps and no coding: copy the connection address, add it to the assistant as a custom connector, and approve access in the browser. Assistants with voice support can take the same questions aloud; in ChatGPT, voice commands use the same MCP connection.

The scale behind it

Altegio is not a startup demo. The company, founded in 2022 and headquartered in Budapest, says it handles 5.5 million bookings every month, its businesses generate a combined turnover of over €100 million a month, and more than 100,000 specialists use the platform every day. Its open API already supports more than 200 methods, and over 100 integrations in the Altegio Marketplace run on it. The team counts more than 130 people across seven offices in the EU, the UAE, Latin America, and Central Asia.

API v3 is designed with AI agents in mind. It adds personal API keys for custom solutions and third-party apps — each key acts on behalf of the user who created it, with that user’s current permissions, so revoking an employee’s access kills their key too. Authorization is password-free, so partner apps never receive the user’s Altegio password. And the API uses consistent terminology for the key entities — location, employee, service, client, booking, visit — so developers and AI agents interpret the data the same way. Developers can also build their own add-ons through the Integrations Hub MCP and sell them to Altegio’s client base of over 14,000 businesses. The pattern is familiar from other platforms opening the same door — Workato handed its enterprise AI engine to self-serve builders with MCP servers last month — but Altegio is aiming it at a far less technical audience.

“A salon owner doesn’t need another dashboard. They need answers to their questions. MCP delivers those answers today, and API v3 lets partners build the next layer on top of Altegio’s data,” said Yri Petrou, Altegio’s CEO and co-founder. “We believe business data belongs to the business: the more tools that can work with it, the more value the owner gets.”

The catch

Three things temper the launch. First, API v3 is in early access, not general availability — developers can build on it, but the finished surface is still to come. Second, what each assistant can actually do varies by assistant and subscription plan, so the experience in ChatGPT will not match the one in Claude or Cursor feature for feature. Third, the announcement is a press release, not a shipped product review: no pricing was disclosed, no per-app availability dates were given, and nobody outside Altegio has yet tested whether the read-only MCP holds up under a real salon’s daily chaos. The team is demoing the platform at Web Summit this week; the proof will be in the first owners who wire it up and trust it with a Friday-afternoon booking change.

AFP take: Altegio’s launch is what MCP was built for — a boring, essential database answering plain questions for people who never asked for an API. Salons are the right test: if an AI assistant can reliably move a booking and flag lapsed clients here, it can do it anywhere. Watch two things: whether API v3 leaves early access with the same permission model intact, and whether the read-only MCP becomes the default for staff — the moment an assistant can edit the calendar, trust, not features, decides adoption.

Frequently asked questions

What did Altegio announce on November 9, 2026?

An open platform that connects its booking software to AI assistants: six MCP servers built on the Model Context Protocol, plus Business Management API v3 in early access for developers. Altegio announced it at Web Summit 2026 in Lisbon, which runs November 9–12.

What can a salon owner ask an AI assistant once it is connected?

Plain-language questions about the business’s own data — for example, which clients have not visited in over 90 days, moving a client’s appointment to a new time with a named stylist, or how revenue changed this month and which services grew. The assistant answers from bookings, visit history, and revenue data.

Is business data safe when an AI assistant connects to Altegio?

The assistant can only see and change what the user’s Altegio account has permission to access, with read, write, and delete permissions set separately, and it asks the user to confirm before saving any change. Altegio runs on Hetzner data centers in Germany and says it meets GDPR requirements.
